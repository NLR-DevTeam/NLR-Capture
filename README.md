# NLR Capture
<img width="2056" height="1281" alt="image" src="https://github.com/user-attachments/assets/b3975220-e02c-4046-bfeb-314971204879" />

- 简洁高效的网络请求捕获与调试工具。
- 使用 Go 原生 UI，无内置浏览器内核。
- 界面与交互参考 F12 DevTools -> Networks 构建。
- 本地化适配。
- HTTPS 解密，自动响应改写，断点，编辑与重放，低学习成本的交互。

# 构建
- 需要 Go 1.27.1+，其余依赖项自动下载。
- Windows：`build-win.ps1`
- Linux：`build-linux.sh`
- Build Linux ver on Windows：`build-linux.ps1`
